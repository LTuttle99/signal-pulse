# Provider and usage-rights review

Reviewed November 5, 2026. Availability and terms can change. This review records implementation choices; it does not claim a blanket license for commercial republication.

| Source | Verified offering / limits | Implementation decision |
|---|---|---|
| [TradingView widgets](https://www.tradingview.com/widget-docs/) | Official free embeddable ticker tape, advanced chart, market overview, screener, and fundamentals widgets; coverage and data delay depend on instruments/exchanges. Required attribution retained. | Used for public display. No DOM/iframe price extraction, scraping, or quote persistence. Ticker CFDs are labeled as CFDs. |
| [Twelve Data pricing](https://twelvedata.com/pricing) | Basic lists 8 credits/minute, 800/day, and internal non-display usage. Other plans distinguish internal display and commercial rights. | Not used. A free key does not establish public display or redistribution rights. Historical endpoints are not invoked. |
| [Massive stocks pricing](https://massive.com/pricing?product=stocks) | Individual Basic advertises 5 calls/minute and two years of historical access; business offerings are separate. | Not used. Individual historical access does not establish this site's public quote redistribution rights. |
| [Alpha Vantage support](https://www.alphavantage.co/support/) | Free service states 25 requests/day. [Terms](https://www.alphavantage.co/terms_of_service/) and [market data policy](https://www.alphavantage.co/realtime_data_policy/) distinguish personal use and commercial entitlements. | Not used. No established public quote redistribution entitlement; no API key requested. |
| [NPR terms](https://www.npr.org/about-npr/179876898/terms-of-use) | Attributed personal noncommercial feed display is permitted, with direct original links and other stated conditions. Commercial/publication uses need separate review. | National, business, and technology RSS metadata only. Publisher is always NPR, so three feeds never inflate distinct-outlet counts. No body text/images. Headline anchors link directly to NPR; Coverage navigation is a separate link. |
| [PBS terms](https://www.pbs.org/about/about-pbs/terms-of-use/) | General personal-use rules prohibit commercial exploitation; no broader commercial redistribution permission is assumed. | Personal noncommercial headline/link display only, national and economy feeds. No full text, descriptions, or images copied. Commercial reuse is excluded. |
| [Federal Reserve RSS](https://www.federalreserve.gov/feeds/feeds.htm) | Official release metadata; feed endpoint verified successfully. | Attributed official releases with original links, hourly source cadence. |
| [NASA news releases](https://www.nasa.gov/news-release/feed/) | Public government feed returned valid RSS; content scope includes some science features as well as releases. | Metadata only, hourly cadence. No publisher images or NASA branding copied. Source category does not certify national significance. |
| [GDELT DOC 2.0](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/) | Verification request returned HTTP 429 with a rate-limit message. Underlying publisher copyrights remain. | Disabled. No fictitious successful discovery results. |
| [BLS API documentation](https://www.bls.gov/developers/api_signature_v2.htm) and [FAQ](https://www.bls.gov/developers/api_faqs.htm) | Keyless public API; unregistered limit 25 queries/day. Exact three series verified: CUSR0000SA0, LNS14000000, CES0000000001. | Once-daily government data fallback, three API requests/day in normal operation. Original monthly observation dates, units, and seasonal-adjustment notes retained. No publication timestamp invented. |
| [BLS release calendar](https://www.bls.gov/schedule/news_release/) | Official [iCalendar](https://www.bls.gov/schedule/news_release/bls.ics) successfully verified. | Once-daily confirmed date-only calendar. Past/canceled events omitted; no time-zone conversion or guessed event times. |
| [FRED API terms](https://fred.stlouisfed.org/docs/api/terms_of_use.html) | Owner API key required; series can carry third-party restrictions. Government-origin series selected; original units/frequency/vintages retained. | Connector and authenticated Cloudflare-secret relay implemented; key absent, so live FRED integration not claimed. UMCSENT excluded pending University of Michigan display permission. |
| [SEC API documentation](https://www.sec.gov/edgar/sec-api-documentation) and [developer resources](https://www.sec.gov/about/developer-resources) | Submissions/XBRL APIs require no paid account, but an identifying User-Agent and fair access are required. Published ceiling: 10 requests/sec. | Connector implemented for the curated CIK universe; actual contact missing, so no live SEC request is made with an invented identity. Sequential requests limited to at most 2/sec. |
| [NewsAPI pricing](https://newsapi.org/pricing) | Developer plan is for development/testing. | Excluded from production. |

Successful feed/BLS response hashes, actual last-success times, record counts, and status are recorded in `source-verification.json`. A successful fetch demonstrates endpoint/schema availability, not commercial licensing. TradingView widget rendering was visually verified in the local browser; widgets' current prices are not copied into this report or database.

The app does not claim comprehensive publisher, company, sector, exchange, or international coverage. Source failures never generate replacement stories or fabricated prices. Metadata summaries describe observed reports and publisher counts rather than asserting unverified facts.
